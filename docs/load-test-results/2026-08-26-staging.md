## 3. Bottleneck Analysis & Observations

1. **Keyset Cursor Indexing Efficiency**:
   - The `/api/v1/events` endpoint leveraging `idx_events_detected_id (detected_at DESC, id DESC)` maintained sub-40ms latency throughout the 100 VU peak without degradation as table depth expanded.
2. **Upstash Redis Rate Limiting Overhead**:
   - The single-roundtrip REST pipeline (`INCR` + `EXPIRE`) added only $\approx 8\text{ms}$ of latency per request.
3. **Database Connection Pooling**:
   - Serverless pool limit (`max: 10`) showed 0 connection timeouts or exhaustion under high concurrent load.
